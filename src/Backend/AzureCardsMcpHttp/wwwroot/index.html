🔑 Gerador de API Key — Azure Cards MCP

O servidor MCP recebe um único header, x-api-key, que junta numa só string a sua chave de acesso ao MCP e, opcionalmente, o projeto e a credencial do Azure DevOps. Esta página monta essa string para você — e também faz o caminho inverso.

1. Identifique-seInforme a chave MCP que o administrador do servidor liberou para você.
2. Gere a keyPreencha o projeto e o PAT do Azure DevOps (ou deixe em branco para usar os do servidor).
3. Use no clienteCopie a key e cadastre-a no header x-api-key do Claude Code, Copilot Studio etc.

1 Sua chave MCP

Necessária para usar esta página: o servidor só gera ou decodifica keys para quem tem uma chave válida.

É uma das chaves cadastradas em McpAuth:ApiKeys no servidor. Não sabe qual é? Peça a quem administra o servidor.

2 O que você quer fazer?

Gere uma key nova, ou cole uma key existente para conferir o que há dentro dela.

É o caso comum. Desmarque só se a key for para outra pessoa, com outra chave MCP.

Pode colar a URL do board, do backlog ou de um card do projeto — o servidor aproveita só a parte da organização e do projeto.

Crie um PAT em User settings → Personal access tokens no Azure DevOps, com escopo Work Items (Read & write).

💡 Deixando URL e chave do Azure em branco, o servidor usa o projeto e a credencial da configuração dele.

✅ Key gerada

⚠️ Trate a key como uma senha: ela não é criptografada, só embaralhada — quem a tiver consegue recuperar o PAT que está dentro dela. Cada clique em "Gerar" produz uma key diferente, e todas são válidas.
